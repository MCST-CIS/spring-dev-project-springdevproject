Ink And RIFF

Description: This project was made to be a fun 2 player fighting game that represents the two creators as friends in their unique ways. Me and my partner made it as a way to represent ourselves in a fun, playful, and creative way. The game has 2 players, one a punk themed player to represent Natalie and her connection to music, and one an artist themed player to represent Laura and her connection to art.

User controls

Player 1: Arrow keys to move up, down, left, and right ‘D’ key to fire ink (no cooldown)

Player 2: Use right joystick on x-box controller to move To fire press ‘X’ on the controller

Learning Goal:

In our game, the push method is used to instantly create and add a new Bullet object to the bullets array the moment a player presses their attack button. This helps because it allows the game to manage multiple projectiles on the screen at the exact same time. Instead of keeping track of every single bullet as a separate variable, the game can simply loop through that one array to smoothly update all of their movements, draw their images to the canvas, and efficiently check if any of them have collided with an enemy.

The dist() method is a that calculates the exact distance between two points in this case, the center of a bullet and the center of an enemy and then returns that measurement as a number, which the code then temporarily stores in the variable dL. This is useful because it allows the game to mathematically check if that returned distance is small enough to count as a collision, letting the game engine know exactly when a bullet has successfully hit an enemy.

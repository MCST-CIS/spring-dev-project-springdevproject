Ink And RIFF

Description: This project was made to be a fun 2 player fighting game that represents the two creators as friends in their unique ways. Me and my partner made it as a way to represent ourselves in a fun, playful, and creative way. The game has 2 players, one a punk themed player to represent Natalie and her connection to music, and one an artist themed player to represent Laura and her connection to art.

User controls

Player 1: Arrow keys to move up, down, left, and right ‘D’ key to fire ink (no cooldown)

Player 2: Use right joystick on x-box controller to move To fire press ‘X’ on the controller

Learning Goal:

In our game, the display() method is used to instantly create and add a new Bullet object to the bullets array the moment a player presses their attack button. This helps because it allows the game to manage multiple projectiles on the screen at the exact same time. Instead of keeping track of every single bullet as a separate variable, the game can simply loop through that one array to smoothly update all of their movements, draw their images to the canvas, and efficiently check if any of them have collided with an enemy.

The keyPressed() method stores the value of if, when, or can a bullet be fired. It is useful since when you win the game it returns no value so you can't continue firing. It also helps check when you press r to restart the game, or are pressing abutton to fire a bullet.

LLM Assistance:

Nearly all of our work was made without LLMs. We only used LLMs to help translate code from one coding language to another. This made our developement process quicker since it would have taken up a lot of time to try and change all of our code to a different language. Though, the LLM still made some mistakes in the code that needed to be fixed manually, but overall it helped bring down the developement time.
